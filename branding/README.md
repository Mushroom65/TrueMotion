# True Motion artwork

`true-motion-source.png` is the exact 1280 × 1280 PNG supplied by the True Motion project owner on 2026-10-30. It replaces the earlier True Motion logo. SHA-256 is recorded in `ASSETS.json`.

`tools/icon/package_true_motion.py` only resizes and centers this artwork. The launcher background is black. Foreground artwork stays within the adaptive icon safe area; the themed icon uses artwork luminance as its alpha mask. The original stays intact.

The upstream icon sources under `tools/icon/` are retained for attribution/history and are not used as the application icon.
