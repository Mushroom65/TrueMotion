# True Motion Next: перенос на AbsentMotion

Экспериментальная сборка 0.12.0 на стабильной базе AbsentMotion v4.3.0. Полный перенос функций не завершён. Пакет `app.truemotion` обновляет предыдущий Next и устанавливается отдельно от старого мода.

[Новые возможности и инструкция 0.12](RELEASE_0_12_RU.md). 575 перенесённых эффектов AfterMotionZ+ сохранены в своих категориях.
