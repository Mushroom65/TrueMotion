# True Motion Classic, 0.14.0

База обновлена до AbsentMotion v4.4.0. Библиотеки распознавания речи и остальные вспомогательные ARM64-библиотеки взяты из официального compatible APK 4.4.0 с проверкой SHA256SUMS. Наш движок собран из объединённых исходников, а не заменён бинарным движком upstream.

Из старого DEX-мода перенесено 1746 определений шейдеров и скриптов. Они находятся в отдельных категориях **True Motion Classic**; исходные эффекты AbsentMotion и 575 эффектов AfterMotionZ+ сохранены отдельно. Всего в каталоге 2546 определений. Исходные идентификаторы параметров, значения селекторов и ключи `.alight` сохраняются при прямой миграции в Classic.

Поддерживаются промежуточные буферы, несколько проходов, выбор групп проходов из JavaScript, встроенные изображения, quaternion-параметры и вычисляемые вершинным шейдером константы. Вершинные программы этого каталога не меняют геометрию: их вычисления перенесены перед фрагментной программой. JavaScript `animate(env, el, p)` выполняется через Rhino с ограничением времени, инструкций и глубины стека, без доступа к Java-классам. Движение, прозрачность, текст и группы шейдеров подключены к рендеру; скрипты не редактируют проект и не создают ключи.

Два XML имели пропущенный пробел между атрибутами корневого элемента. В нескольких шейдерах исправлены несовместимые с SkSL конструкции и невалидные исходные заглушки. Скрипт числового счётчика использует ASCII-совместимые регулярные выражения вместо неподдерживаемого Rhino флага `u`. Три повторяющихся идентификатора параметров сведены к одному с сохранением последнего исходного значения.

**Это не заявление о полном совпадении изображений.** Компиляция и пробный рендер проверяют загрузку и исполнение, но не доказывают совпадение каждого эффекта со старым OpenGL-движком. Производные скорости пока рассчитываются по собственным ключам слоя; движение родителя и предыдущих скриптов может давать другой motion blur. Приложение сохраняет неизвестные эффекты при импорте и показывает их в отчёте.

Все 1769 исходных записей перечислены в [LEGACY_EFFECT_PORT.json](LEGACY_EFFECT_PORT.json): 1746 перенесены, 11 используют имеющиеся правила нативного импорта, ещё 12 требуют отдельной обработки. Среди последних есть две информационные записи об авторах, старые варианты движения по пути, Scatter Repeat, Parent Helper, Grow/Shake Parts, Morph Path, цвет обводки, интервалы текста и палитра. Некоторые из этих настроек читаются существующим импортёром, но полноценная анимация каждого параметра и отдельный интерфейс не подтверждены. Кроме того, шесть исходных шейдеров (Rockfield, Starburst, Simplegrid, Featherfalls, Synthwave, Starglowparticle) ссылаются на отсутствующие в старом пакете скрытые проходы; их загрузка проходит, но точный результат не подтверждён.

Спектрум **True Motion → Audio spectrum / Аудиоспектрум** использует настоящее стерео FFT. Источником может быть конкретный аудио-/видеослой либо общий микс. Есть столбцы, линия, заполненная область, радиальные столбцы, радиальная линия, точки и радиальная область; диапазон частот, цвета, свечение, усиление и ключи. Анализ кэшируется отдельно от кадров; длинные записи автоматически используют более редкую временную сетку, чтобы ограничить память. MP3/WAV и прочие форматы декодируются обычным аудиотрактом приложения, отдельная установка FFmpeg для спектрума не нужна.

Исправлена матрица дочернего слоя при смене якоря родителя: изменение якоря не переносит дочерний объект, последующие поворот и масштаб родителя применяются вокруг того же центра. Проверка Android измеряет обе стадии, в том числе неравномерный масштаб.
