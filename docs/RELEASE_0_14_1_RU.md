# True Motion Next 0.14.1

Исправление конфликта новой цветокоррекции и True Motion Classic. База и C++-движок те же, что в 0.14.0: AbsentMotion v4.4.0.

При открытии проекта импортёр 0.14.0 мог подменять `lab.true.grade` на `tmold.lab.true.grade`. Новые дополнительные параметры при этом сохранялись в XML, но старый шейдер и общий интерфейс их не использовали. Теперь зарегистрированный ID текущего эффекта имеет приоритет перед совпадающим исходным ID Classic.

Уже подменённые экземпляры автоматически возвращаются в новую цветокоррекцию, если в них есть хотя бы один параметр её расширенной схемы. Значения, ключи, easing и состояние видимости сохраняются. Настоящий Classic-эффект со старой схемой остаётся Classic; в библиотеке его имя дополнено пометкой Classic / 旧版. Ручной выбор старого эффекта не запрещён.

Установите **True Motion v0.4.1 Beta.apk** поверх предыдущего True Motion Next и заново откройте проект. Если проект уже открыт, сначала выйдите в список проектов. Старые APK не заменены, исходный DEX-мод не затрагивается. Для экземпляра с вручную изменённой или обрезанной схемой автоматическое восстановление не гарантируется.

Проверки: до исправления три из четырёх новых регрессионных проверок воспроизводили подмену. После исправления пройдены все 83 проверки импорта, цветокоррекции и каталога в выбранных 13 классах, без пропусков. В MuMu Android 15 воспроизведена ошибка на 0.14.0, затем проверены обновление поверх неё, восстановление двух 53-параметрических экземпляров, сохранение намеренно выбранного 29-параметрического Classic, HSL-панель и повторное открытие через список проектов. Значения и ключи сверены с XML до обновления; C++-ядро не менялось. Физический телефон не проверен.
