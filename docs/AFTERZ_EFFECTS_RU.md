# Эффекты AfterMotionZ+ в True Motion Next 0.11

Свежий источник — предоставленный `AfterMotionZ+ Clone.apk`, SHA-256 `18e671ed09a15538fed7f2a8c958123a1c2e30b9ac2ebf32530d7751db42293d`. Прежний каталог APK-мода True Motion не использовался как источник новых шейдеров.

Из 834 определений адаптированы 575. Добавлены 447 правил распознавания исходных ID при импорте; прежние 207 правил сохранены без изменений. Ключи и кривые анимации переносятся. Они находятся в отдельных категориях **AfterMotionZ+**: цвет и свет, размытие и свечение, искажения, генераторы, контур и рисование, преобразования, 3D, непрозрачность, маски и кеинг, повтор, прочее. Пустая категория «Текст» скрыта до появления совместимых эффектов. Все 198 ранее существовавших JSON-определений сохранены побайтно; новые runtime ID начинаются с `amz.` и не заменяют `absent.*`.

Включены Deep Glow AE, Deep Glow Multipass и Saber AE. Новый runtime поддерживает несколько проходов, промежуточные буферы с уменьшением до 128 раз, чтение изображения под слоем, итерации, исходные значения переключателей выбора и параметры XYZ. Параметры сохраняют исходные ID и ключи. Большие панели разбиты на сворачиваемые разделы.

Шейдеры компилируются при первом использовании. Сам каталог загружается один раз для текущего языка; открытие категории не запускает компиляцию сотен эффектов. 439 миниатюр взяты из донора, 136 отсутствовавших превью созданы native-движком на контрольном слое. Миниатюры статические, список использует существующую ленивую сетку. Некоторые сложные эффекты всё равно дороги: первый рендер Displacer Pro AE в MuMu занял около 24 секунд. Это проверка эмулятора, а не показатель скорости физического телефона.

Категории переведены на русский, английский и упрощённый китайский. Используются переводы донора, переводы общих названий параметров и отдельный словарь новых разделов. Отсутствующие переводы описаний и редких параметров остаются на английском.

## Проверено

- 575 из 575 шейдерных определений успешно скомпилированы непосредственно в Android; все 575 отрендерены на контрольном слое.
- Deep Glow AE / Multipass / Saber: свечение за пределами исходной альфы, изменение параметров, сохранение и повторное открытие.
- Медиа с Checker: после перемещения на 16 пикселей текстура совпала в локальных координатах слоя, 0 отличающихся каналов при допуске 2/255.
- Depth Relight: чтение и затемнение изображения из нижнего слоя.
- PNG и точный экспорт Deep Glow совпали с предпросмотром; средняя ошибка MP4 после независимого декодирования — 0,9001/255.
- Повторная native-регрессия существующих инструментов: группы, частицы, звук, траектории, GIF, пререндер и экспорт. В каталоге доступны все 773 определения.
- 1257 JVM-тестов: 0 ошибок, 12 пропусков по условиям среды.
- В интерфейсе проверены отдельные категории, прокрутка и открытие параметров Deep Glow AE.

Проверки выполнены в MuMu Android 15, ARM64 через трансляцию. Физический телефон не проверялся. Полное визуальное совпадение каждого эффекта с донорским приложением не установлено. Прозрачный результат на пустом фоне у межслойного эффекта может быть ожидаемым: например, Depth Relight по умолчанию читает фотографию снизу.

## Осталось

259 определений не включены в каталог: vertex/geometry-проходы, JavaScript/геометрия, собственные native-операции донора, внешние текстуры, некоторые виджеты и зависимости отдельных проходов. Они не заменены заглушками. В частности, наличие новых Deep Glow AE и Saber AE не означает, что перенесён каждый вариант DeepGlow Enhanced или весь набор исходных 3D-эффектов.

Точные статусы, причины, хэши источников и происхождение миниатюр: [AFTERZ_EFFECT_PORT.json](AFTERZ_EFFECT_PORT.json). Другие незавершённые части всего приложения перечислены в [TRUE_MOTION_MIGRATION_RU.md](TRUE_MOTION_MIGRATION_RU.md).

## Воспроизведение конвертации

Инструменты находятся в `tools/afterz/`. Нужны Python, lxml, Pillow, skia-python 144.0.post2 и C-препроцессор. Они принимают собственный локальный APK и приватный каталог с декодированными XML в `effects-source/` и дампом строк Android `resources-dump.txt`. Декодер, donor DEX, native-библиотека расшифровки и APK не входят в репозиторий.

```sh
python tools/afterz/convert.py --workdir PRIVATE_DIR --apk DONOR.apk --prepare
python tools/afterz/preprocess.py --workdir PRIVATE_DIR
python tools/afterz/convert.py --workdir PRIVATE_DIR --apk DONOR.apk
python tools/afterz/install.py --workdir PRIVATE_DIR --apk DONOR.apk --previews NATIVE_PREVIEW_DIR
```

Без `--previews` для отсутствующих в доноре миниатюр используется фон прозрачности. Снимки `render-afterz-N.png` создаёт Android-инструментация `PortInstrumentation` с аргументом `afterz=true`. Конвертер отклоняет неизвестные операции и сохраняет причину в отчёте. Это адаптер данного закреплённого донора, а не универсальный импорт любого XML/GLSL.

Исходные авторы Alight Motion, Toji Motion и AbsentMotion сохранены. Эффекты и доступные миниатюры адаптированы из предоставленного AfterMotionZ+; в источнике также присутствуют названия NextMotion и SATRIYAID. Это отдельное происхождение данных, а не заявление об авторстве True Motion над исходными алгоритмами.
