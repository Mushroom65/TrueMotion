# True Motion Next 0.13.0

Основа — AbsentMotion v4.3.0, пакет `app.truemotion`.

## Что изменилось

- Исправлена геометрия импортированных `.alight`/XML: исходное смещение якоря применяется до поворота и масштаба. Родитель и потомок соединяются полной матрицей, поэтому неравномерный масштаб и вложенные повороты не теряют скос. Значения и ключевые кадры проекта сохраняются.
- XML без деклараций медиа снова находит существующий доступный системный файл. Поиск по имени применяется только при единственном совпадении; чужие приватные пути не открываются.
- В редакторе частиц в разделе «Эмиттер» появился выбор генерации 2D/3D. В режиме 3D каждая частица имеет собственное положение и глубину в сцене и проецируется камерой проекта. Поворот эмиттера по X/Y больше не превращает облако в плоскую текстуру. Текстуры частиц смотрят на камеру.
- Исправлены рамка выделения и нажатие по 3D-облаку, плоская физика в режиме 2D и инициализация матрицы наклонённой камеры.

## Как проверить старый проект

Установи APK поверх предыдущего True Motion Next и заново импортируй исходный `.alight`. Геометрический признак добавляется при импорте; сохранённая ранее неверно импортированная копия автоматически не переделывается. Исходный пакет и старое приложение сохраняются.

Для 3D-частиц: выбери эффект частиц → «Эмиттер» → «Генерация» → «3D». Настрой глубину спавна и поворот слоя/камеры. Проекты без нового параметра сохраняют прежнее поведение; новый режим включается явно.

## Проверки и ограничения

MuMu, Android 15: реальный Project 122 с 7 файлами медиа, вложенные матрицы и якоря, размеры групп 80/320/640, 3D-частицы при повороте на 90°, глубина, камера проекта, выделение, сохранение/открытие, OpenGL, PNG и MP4. Полный отчёт прилагается к сборке. Физический телефон не проверен.

Случай штатной обводки со смещением/обрезанием остаётся в диагностике: базовые фигуры, перенос группы, прозрачность и нейтральный фильтр проходят без смещения. Полный перенос старой библиотеки эффектов True Motion ещё не завершён. Текущие 575 AfterMotionZ+ эффектов находятся в своих категориях. Эти пункты не объявляются исправленными или полностью перенесёнными без проверки.
