# Предпросмотр и замена медиа, 0.14.0

В «Заливка и цвет» у медиа-заливки появилась кнопка **Заменить медиа**. Меняется только выбранный слой; другие слои, использующие исходный файл, сохраняют свою ссылку. Ключи, эффекты, геометрия, положение, режим заполнения и длительность слоя сохраняются. Для более короткого нового видео недоступная начальная точка обрезки сбрасывается внутрь нового файла. Старый файл остаётся доступен для отмены.

Устранена причина пустого спектрума в остановленном предпросмотре: фоновая подготовка аудио теперь обнаруживает не только Audio Motion, но и Spectrum. После завершения анализа обновляются привязки движка и версия ресурсов кэша. Автоматический кэш не записывает кадр с ещё неподготовленным аудиозависимым эффектом.

Кэш хранит PNG с прозрачностью вместо JPEG с заранее наложенной шахматной подложкой. Подложка рисуется во вьюпорте в том же масштабе, что и в живом режиме. Растровый кадр небольшого проекта может быть отрисован под фактический размер предпросмотра, с общим пределом 1920 пикселей по длинной стороне. Кадр меньшего качества больше не включается как замена более чёткого живого предпросмотра. Лимит дискового кэша 2 ГиБ сохранён.

Для семейства OnePlus Nord 5 / OnePlus с SM8635 введён консервативный начальный выбор OpenGL по полученному пользовательскому отчёту об артефактах. Сбой GPU теперь помечает соответствующий бэкенд как проблемный, чтобы восстановление могло выбрать другой. Неудачное или пустое тестовое изображение больше не считается успешной проверкой GPU. Бюджет переиспользуемых ресурсов Skia установлен в 128 МиБ на контекст; это не жёсткий предел всей памяти активной сцены.

**OnePlus физически не проверялся.** Выбор OpenGL — обходной путь до получения лога. Причина конкретного вылета через 5–10 минут не установлена; без стека ошибки, версии драйвера и проверки на устройстве нельзя заявлять, что этот вылет устранён.

При импорте обычного XML Alight используются проверенные нативные соответствия AbsentMotion. Пакеты старых модов с соответствующим `am` используют схемы Classic; расширение `trueLegacyEffects="true"` позволяет явно указать этот режим в XML. Специальные нативные инструменты True Motion сохраняют свои отдельные правила миграции. Версионный суффикс стандартного `com.alightcreative.motion/…` не включает режим мода.

Нижний предел скорости теперь согласован с базой 4.4.0: 0,05×; верхний предел True Motion остаётся 100×. Интерфейс и расчёт временной шкалы используют один диапазон.
