# Траектории — True Motion Next 0.8.0

Выбери слой → «Трансформация» → «Траектория». Второй вход: «Студия True Motion» → «Анимация» → «Траектория».

Если у положения ещё нет двух ключей, кнопка «Создать траекторию» добавляет начальный и конечный ключи. Уже существующие ключи можно редактировать сразу.

- На схеме перетаскивай точки положения и круглые ручки Безье. Для точного ввода выбери «Точка», «Входящая» или «Исходящая» и нажми на X/Y.
- «Сгладить всё» рассчитывает ручки с учётом расстояния во времени между ключами; «Сгладить ключ» меняет выбранный ключ. «Угол» обнуляет его ручки. Сегмент без ручек остаётся прямым с прежней интерполяцией.
- «Связать ручки» сохраняет противоположное направление и длину второй ручки. Отключи для независимого редактирования.
- «Кривые» временно отключает пространственное сглаживание, сохраняя ручки. «Автоповорот» добавляет угол касательной к обычному повороту слоя, не переписывая его ключи.
- Номера ключей перемещают таймлайн к выбранной точке. Двумя пальцами можно двигать и масштабировать схему; «Вписать» возвращает общий вид. Координаты схемы относятся к родителю слоя. Основной вьюпорт продолжает показывать композицию.

Траектория считается непосредственно нативным движком: в предпросмотре, выделении, экспорте PNG/MP4 и внутри групп. На каждый кадр не создаются новые ключи и XML. Z интерполируется отдельно, как раньше; ручки и автоповорот относятся к плоскости XY. Автоповорот использует касательную пути, а не производную временного easing.

Один жест с ручкой отменяется одной командой Undo. Копирование трансформации сохраняет ручки и автоповорот; реверс ключей меняет входящие и исходящие ручки местами. Фотослой из видео сохраняет текущий автоповорот. При смене родителя преобразование пересчитывается в ключи по кадрам для сохранения геометрии; исходные ручки при этом заменяются результатом пересчёта.

Проект хранит `truePath` на `transform/location`, относительные `pathIn`/`pathOut` на его `kf` и `trueAutoOrient` на `transform`. При чтении наших старых `lab.toji.motionPath`/`lab.toji.motionpath` четыре канала ручек переносятся в эти атрибуты. Исходный эффект остаётся скрытым с меткой `truePathConverted`, чтобы сохранить исходные параметры. Выключенные старые эффекты не включаются автоматически. Проверена наша схема данных на синтетическом проекте; это не утверждение о полной совместимости всех старых `.alight`.

Проверки сборки: 196 целевых JVM-тестов, 7 проверок математики пути на C++, прежние проверки аудиосигнала и частиц; MuMu — нативная геометрия/угол в 11 моментах, easing, группы, Undo/Redo, сохранение и старые параметры. MP4 дополнительно декодирован независимым FFmpeg и сравнен с PNG движка. Ручные UI-проверки выполнялись в MuMu; физический телефон не проверялся. Полный перенос функций ещё не завершён.
