# True Motion Next 0.9.0 — основа AbsentMotion 4.0.0

Основа закреплена на релизе `v4.0.0`, коммит `2103de26761868c556441563c087f3d818e40ba0`: https://github.com/Comett1225/AbsentMotion/releases/tag/v4.0.0.

Обновление собрано в отдельном каталоге `work/research/AbsentMotion-v4`. Каталог `AbsentMotion`, APK и исходники 0.8.0 сохранены. Пакет приложения остаётся `app.truemotion`: APK обновляет True Motion Next; прежний мод `com.alightcreative.tojimotionlab` не удаляется.

## Пререндер во вьюпорте

На панели воспроизведения появилась кнопка с двумя треугольниками внутри экрана. Нажми её, чтобы отрендерить предпросмотр. Затем воспроизведение использует готовые кадры. Повторное нажатие показывает доступный диапазон; удержание очищает кэш. Во время подготовки кнопка останавливает пререндер.

Готовый диапазон отмечается зелёной линией на шкале времени, а при достаточном масштабе — точками кадров. После изменения проекта метки пропадают и прежний кэш не воспроизводится. Undo может вернуть подходящий кэш. Редактирование на паузе использует живой движок.

Дисковый кэш ограничен **2 ГиБ**; фактический бюджет уменьшается при нехватке свободного места. В оперативную память 2 ГиБ не выделяются: сохранены адаптивный предел и небольшой пул декодированных кадров. JPEG используется только для предпросмотра. Экспорт продолжает работать с исходной сценой. Это ручной пререндер; автоматическое сохранение каждого просматриваемого кадра пока не перенесено. Кэш временный и может очищаться при закрытии проекта или освобождении ресурсов Android.

## GIF

Добавляй GIF через «Медиа» или выбор файла. Анимация импортируется как зацикленный клип. Для прозрачной GIF создаётся группа с видеомаской. Она остаётся анимированной после сохранения и открытия проекта. Взяты ограничения декодера 4.0: до 2048 × 2048, 3000 кадров и 10 минут.

## Сохранённые инструменты True Motion

Перенесены на новую основу цветокоррекция с UI, звуковая анимация без ключей, частицы, траектории, якорь, редактирование групп, фотослои, скорость до 100×, JS-плагины и векторный редактор. При объединении исправлены взаимодействие групп с пакетированием редактирования по кадрам, удержание последнего кадра только при выходе за содержимое группы и пересчёт траектории при смене родителя.

Нативный движок пересобран из объединённых исходников. Остальные восемь `.so` взяты из официального совместимого APK 4.0.0, SHA-256 которого проверен по опубликованному `SHA256SUMS.txt`. Сохранён проверенный путь экспорта через чтение пикселей для ARM-трансляции MuMu, согласованный с новым поворотом кодировщика.

Эта сборка использует вариант **compat, Android 9+**. Возможности современных `foss`/`play`, отсутствующие в compat (включая AI Enhance, AI Smooth и новый AI-вырезатель 2.0), не объявляются перенесёнными.

## Проверка и ограничения

- 1252 JVM-проверки под Linux: 0 ошибок, 12 пропусков по условиям среды. Дополнительно пройдены целевые Windows-проверки совместимости и нативная математика аудио, частиц и траекторий.
- В MuMu все 198 определений каталога загружаются движком без ошибок компиляции; это не визуальное подтверждение каждого эффекта. Отдельно проверены наши 17 эффектов и прежние функциональные сценарии.
- Проверены пререндер 60 кадров, совпадение с живым рендером, отмена/очистка, недействительность после редактирования и повторное использование после Undo.
- Проверены два цикла трёхкадровой GIF, прозрачность, сохранение и повторное открытие; исходный тестовый GIF находится в исходниках.
- PNG и MP4 проверены, в том числе независимым декодированием. Ручные UI-проверки выполнены в MuMu; физический телефон не проверялся.

Наши основные панели и новые кнопки пререндера переведены на русский, английский и упрощённый китайский. Для части интерфейса основы сохранён английский fallback; полным китайским переводом всей основы это не является. Аналогичный fallback оставлен для наших эффектов в новых локалях fa/bn.

Полный перенос функций не завершён. 3D-редактор, риги, warp deformer, вся библиотека старых модов и независимый Windows-рендерер остаются отдельными задачами в `TRUE_MOTION_MIGRATION.json`.
