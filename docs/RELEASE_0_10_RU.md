# True Motion Next 0.10.0 — 30 октября 2026

Эта версия обновляет пользовательскую иконку и публикует исходники проекта. Основа остаётся AbsentMotion 4.0.0; список незавершённых функций находится в TRUE_MOTION_MIGRATION_RU.md.

Новая иконка установлена на главном экране, в разделе «О приложении» и в Android. Предусмотрены адаптивный и монохромный варианты; исходный PNG сохранён без изменений. Прежние авторы и ссылка t.me/TrueMoti0n сохранены.

Локальный APK: `TrueMotion-Next-0.10.0-2026.10.30.apk`, 83 594 391 байт.
SHA-256: `883b15079d8d0afd0d15a545bc40d85968ab3bf9896cc31d534cab1fdf72ec10`.

Проверены сборка, подпись и установка в MuMu; установленный APK побайтно совпал с подготовленным. Визуально проверены главный экран, сведения Android и раздел с авторами и ссылкой исходников. Изображения в собранных ресурсах совпали с подготовленными. Светлая тема проверялась в приложении, тёмная — в сведениях Android. Исходный APK-мод и предыдущая сборка 0.9.0 сохранены. Реальный телефон в этой проверке не использовался.

C++ код и native-ядро не менялись. Добавлена проверка хэшей, учитывающая только различие окончаний строк между checkout Windows и Linux. В GitHub Actions на исходниках 0.10.0 повторно выполнены 1 252 JVM теста: 0 ошибок, 8 пропусков. Собран compatible APK, прошли проверки исходников и native-библиотек. Подготовлены инструкция сборки и GitHub Actions. Проверка исходников исключает локальные SDK-настройки, ключи, файлы сборки и известные форматы токенов; она не является гарантией обнаружения любых секретов. В репозитории сохранена история исходного проекта, а изменения True Motion идут отдельными коммитами.

Артефакт CI имеет собственную отладочную подпись GitHub runner. Для обновления ранее установленной локальной сборки используй APK с прежней локальной подписью, а не CI APK. Ключи подписи в репозиторий не загружались.
