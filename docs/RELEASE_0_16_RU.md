# True Motion 0.16.0 — библиотека слоя и риг во вьюпорте

Переделка интерфейса 0.15 по обратной связи. Новые инструменты встроены в основной редактор: отдельные окна библиотеки и моделей удалены.

## Библиотека в свойствах слоя

1. Выберите медиаслой и откройте **Библиотека** рядом с **Трансформацией** и **Эффектами**.
2. В сетке видны миниатюры изображений и видео. **+** открывает системную галерею с множественным выбором, как другие средства выбора медиа приложения. Импорт добавляет файлы в палитру этого слоя, без новых слоёв и без новых ключей.
3. До создания анимации нажатие на миниатюру меняет обычную заливку слоя.
4. Для замены по времени поставьте курсор на нужный кадр, нажмите **◆** в этой панели и выберите миниатюру. Выбранный источник удерживается до следующего ключа. На анимированной дорожке смена источника доступна на созданном ключе: на другом кадре сначала нажмите ◆.
5. Кнопка ◆ также удаляет ключ. После удаления единственного ключа возвращается обычный медиаслой. Стрелки переводят между ключами. Основной таймлайн остаётся доступен.

Палитры разных слоёв независимы. Неиспользуемые файлы палитры сохраняются с этим слоем и входят в пакет проекта / «Мои ресурсы», но не загружаются как полноразмерные картинки для рендера. Старые проектные библиотеки 0.15 доступны как начальные палитры для совместимости.

Исправлено чтение миниатюр медиа, скопированных во внутреннюю папку проекта: теперь есть декодирование локальных изображений и кадров видео, а не только обращение к MediaStore.

Существующие ограничения дорожки замены: каждый видеоключ начинает видео с начала, со скоростью 1× и зацикливанием; новая картинка заполняет прежний контур. Аудио не поддерживает ключи замены в этой панели. GIF как библиотечный источник используется статически; существующий импорт анимированного GIF через обычную вкладку медиа сохранён.

## Риггинг во вьюпорте

1. Выберите изображение, фигуру, текст или группу и нажмите **Риггинг** в свойствах слоя.
2. В режиме **Кость** протяните кость по выбранной детали. Деталь привязывается сразу, без создания нуль-слоя и без выбора родителя в списке.
3. Выберите следующую деталь прямо во вьюпорте или на таймлайне. Начните новую кость с видимого конца существующей — получится цепочка. Нажатие на существующую кость в режиме рисования сразу привязывает к ней выбранную деталь.
4. В режиме **Поза** тяните конец кости для поворота. Корневой сустав перемещает риг. **IK** управляет цепочкой из двух костей перетаскиванием конца, со сменой стороны сгиба.
5. **Автоключи** записывают позы при перетаскивании; ◆ добавляет или удаляет ключ поворота выбранной кости. Ключи выбираются кнопками непосредственно во вьюпорте. Масштабирование и перемещение вида доступны двумя пальцами. Галочка завершения всегда видна справа в панели инструментов.

Кости — отдельные узлы рига в проекте, они не отображаются обычными слоями таймлайна. Старые кости 0.15 автоматически преобразуются из нуль-слоёв. Экспорт использует существующий нативный вычислитель иерархий; внутренние совместимые узлы создаются только на границе рендера.

Это риг из отдельных деталей. Деформация сетки, веса вершин, Smart Bones, живые IK-ограничения и импорт `.moho` не реализованы. IK рассчитана на обычную двумерную цепочку из двух костей.

## Мои ресурсы

Отдельный каталог сохраняемых моделей удалён. Сохраняйте через существующее **Мои ресурсы**. При сохранении привязанной детали сохраняется связанный риг; группы сохраняют редактируемые кости. Вставка ресурса копирует ID костей и связей. Сохранённые в 0.15 модели переносятся в «Мои ресурсы» при запуске; исходные файлы старого каталога не удаляются.

Локально: 1 727 JVM-тестов, 1 701 пройден, 26 пропущены по окружению, 0 ошибок. APK собран, minSdk/версия/ARM64 и подпись проверены; аудит исходников и native-хеши пройдены. Итог CI указан в GitHub Release.

Preview APK: ARM64, minSdk 26, debug-подпись. Установка поверх APK с другой подписью может быть невозможна. Новые жесты и интерфейс не проверялись на физическом Android-устройстве в этой сессии. Перед сменой установки экспортируйте проекты пакетами.
