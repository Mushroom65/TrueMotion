# Группы в True Motion Next 0.6

Выберите группу на таймлайне → **Редактировать группу**. Открывается её собственный таймлайн: можно менять слои, ключи, эффекты, текст, добавлять медиа и заходить в следующие группы. Сверху виден путь композиции.

Назад сначала закрывает текущий инструмент и выделение, затем возвращает на уровень выше. Кнопка возврата слева сверху делает то же самое. Положение времени, масштаб и сдвиг вьюпорта родителя восстанавливаются. Весь проект использует общую историю Undo/Redo.

Сохранение, аварийное восстановление и версии всегда записывают весь проект, даже если редактируется вложенная группа. Локальное изменение связанного элемента отделяет его копию от библиотеки; оригинал элемента не меняется. До первого изменения об этом показывается подсказка.

При удлинении обычной группы теперь удерживается последний кадр. Содержимое и время ключей внутри не растягиваются автоматически. Исправляются также обычные группы, уже удлинённые в старой сборке.

В инструментах выбранной группы прокрутите ниже плиток до **Время группы**:

- **Стоп-кадр** — удержание конца анимации;
- **Растянуть** — воспроизведение внутренней анимации по длительности группы;
- **Зациклить** — повтор внутренней анимации;
- **Пусто** — прозрачность после окончания содержимого;
- **Продолжать** — внутренние часы идут дальше, слои видны только в своих интервалах.

Надписи режимов берутся из текущего перевода приложения. Выбранный вручную режим сохраняется и не заменяется автоматическим удержанием. Необычная или анимированная скорость импортированной группы автоматически не переводится в удержание: её время требует отдельной настройки.

При удержании видео остаётся последний кадр; исходный звук после конца не повторяется. В редакторе группы видна длительность её содержимого, а длительность внешнего слоя меняется в родительском проекте. Если новые внутренние слои длиннее внешней группы, продлите внешний слой.

Экспорт из вложенного редактора экспортирует открытую композицию. Для экспорта всего проекта вернитесь на корневой уровень.

Проверено на MuMu Android 15: два уровня вложенности, изменение ключа с одной отменой/повтором, сохранение корня и повторное открытие, все режимы времени, точное удержание видеокадра, PNG и MP4. RU/EN/简体中文. Физический телефон не проверен; ускорение общего рендера в этой версии не заявляется.
