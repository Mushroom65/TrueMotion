# True Motion Next 0.10.0

Проверочная отдельная версия на исходниках AbsentMotion 4.0.0. Пакет `app.truemotion`: устанавливается рядом с прежним True Motion.

Полный список функций и честные статусы переноса: [docs/TRUE_MOTION_MIGRATION_RU.md](docs/TRUE_MOTION_MIGRATION_RU.md).

Цветокоррекция теперь открывается напрямую из инструментов слоя и имеет нативные колёса, кривые и HSL; инструкция — docs/COLOR_GRADE_UI_RU.md.

Добавлена нативная панель «Анимация от звука»: реакция четырёх свойств на аудио/видео, частотные диапазоны, предпросмотр во вьюпорте до применения, BPM/метки и настраиваемый Bop. По умолчанию это живой нативный эффект со ссылкой на аудиослой, без создания ключей; режим запекания оставлен отдельно. Добавлен якорь слоя с X/Y, девятью положениями и компенсацией позиции. Инструкция и ограничения — docs/AUDIO_MOTION_UI_RU.md. Универсальный граф межслойных эффектов ещё не завершён.

Главная точка входа новых инструментов — значок четырёх квадратов в верхней панели проекта. Векторный редактор находится в категории Слои; плагины включаются отдельно.

Сборка Windows: JDK 21, Android SDK 37.0, затем `gradlew.bat -PtrueMotionNativePrebuilt=true :app:assembleCompatDebug`. Путь SDK задаётся локально через ANDROID_HOME или local.properties. Native binary лежит в app/native-prebuilt: libamengine.so пересобрана из текущих C++ исходников и pinned Skia, остальные библиотеки — matching upstream. Происхождение записано в docs/TRUE_MOTION_PROVENANCE.json; пересборка ядра описана в docs/NATIVE_AUDIO_BUILD_RU.md. Для изменений C++ нужен полный маршрут docs/BUILD.md.

Исходный AbsentMotion распространяется по Apache 2.0; исходные NOTICE, LICENSE и THIRD_PARTY_NOTICES.md сохранены. Rhino — MPL 2.0; его лицензия включена в app/src/main/assets/true-licenses. Свои инструменты адаптированы из существующего True Motion; прежние авторы Toji Motion / Alight Motion указаны в credits.

Не завершены Filament-редактор, все старые эффекты, автоматический кэш просматриваемых кадров и Windows-рендерер нового движка. Не следует заменять рабочий старый мод этой экспериментальной веткой.

В 0.5 добавлены нативная физика частиц и панель из пяти разделов, текстуры из других слоёв/групп/скрытого видео, миграция старых параметров и совместимый MP4-экспорт для x86-эмуляторов. Инструкция и ограничения — docs/PARTICLES_UI_RU.md.

В 0.6 добавлены отдельный таймлайн редактирования группы, вложенные группы, общий Undo/Redo, безопасное сохранение всего проекта и удержание кадра при продлении. Есть режимы повтора/растяжения. Инструкция — docs/GROUPS_UI_RU.md.

В 0.7 перенесены «Кадр видео в фото», снимок композиции прямо на таймлайн и управление скоростью до 100× со звуком. Инструкция — docs/VIDEO_TOOLS_UI_RU.md.

В 0.8 добавлен редактор пространственных траекторий с ручками Безье и автоповоротом. Вход — Трансформация → Траектория. Инструкция — docs/MOTION_PATH_UI_RU.md.

В 0.10 обновлена пользовательская иконка, включая адаптивный и монохромный значки Android. Исходный PNG лежит в branding/; ресурсы воспроизводятся tools/icon/package_true_motion.py. Подготовлена сборка GitHub Actions для совместимой версии.

В 0.9 основа обновлена до AbsentMotion v4.0.0 (2103de2). Добавлены кнопка пререндера во вьюпорте, метки готовых кадров, дисковый кэш до 2 ГиБ и анимированный GIF из новой основы. Подробности и ограничения — docs/UPSTREAM_4_UI_RU.md.
